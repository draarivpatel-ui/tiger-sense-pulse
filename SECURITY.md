# Security Policy

## Supported Versions

Security fixes are applied to the current `main` branch of tiger-sense-pulse. Older snapshots and release tags are not separately maintained.

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub Security Advisories:

[Open a private security advisory](https://github.com/draarivpatel-ui/tiger-sense-pulse/security/advisories/new)

Do not open a public issue for a vulnerability report.

Please include enough detail to reproduce the issue, the affected commit or release, and the security impact. You can expect an acknowledgment within 3 business days, an initial triage decision within 14 days, and a fix or mitigation target within 90 days when the report is confirmed.

This project is a TigerData sensor analytics demonstration. Please keep proof-of-concept testing limited to your own copies and test data. Do not access, alter or disclose another user's data.

## Coordinated Disclosure

Reporters and maintainers should coordinate disclosure through the private advisory. A public advisory may be published after a fix is available or after the coordinated disclosure timeline is agreed in the advisory thread.

## Safe Harbor

Good-faith security research that respects privacy, avoids service disruption and follows this policy is welcomed. The maintainers will not pursue legal action against researchers who follow these rules.
